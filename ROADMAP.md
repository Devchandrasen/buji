# Roadmap

These are proposals, not features included in V1.

## Next

- A local-model compatibility suite, including failure behavior for malformed tool calls.
- Better context budgeting with tokenizer-aware limits.
- A full interactive terminal/PTY.
- More file-work examples and clearer per-file review controls.
- Accessibility and keyboard-navigation improvements.

## Explore

- Additional operating systems after platform-specific validation.
- Per-project instructions and reusable task templates.
- Read-only document adapters for selected office formats.
- Optional local authentication headers and provider profiles.

## Longer term

- A separately designed extension/tool interface.
- Worktree-aware isolation and stronger command containment.
- Repeatable coding/task evaluations across local model sizes.

Discuss a concrete workflow in an issue. Features will be prioritized by usefulness, testability and maintenance cost.
